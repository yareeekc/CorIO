## Latest 0.0.4 ALPHA Version futures:

This version introduces a Fullscreen feature. Open windows are now displayed on the bottom taskbar, and the function to create them has been updated to `createWindow(Title, appFile, appLogo)`. In the next release, we will add basic graphical utilities and expand the list of available commands in `backend.sh`.
